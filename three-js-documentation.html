Overview

Extensive Three.js Documentation

Three.js is a lightweight, cross-browser JavaScript library/API used to create and display animated 3D computer graphics in a web browser using WebGL, WebGPU, SVG or CSS3D. This page collects practical, copy-pasteable reference material and code snippets across the entire library surface — rendering, cameras, geometries, materials, lighting, shadows, textures, animation, loaders, controls, physics, effects, particles, helpers, utilities, raycasting, scene management, audio, advanced rendering, WebXR, and exporters.

Quick Start

Install via npm, or use ES module imports directly from a CDN with an import map — no build step required.

npm install
npm install three
CDN import map (no bundler)
<script type="importmap">
{
  "imports": {
    "three": "https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js",
    "three/addons/": "https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/"
  }
}
</script>
Minimal working scene
import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, innerWidth / innerHeight, 0.1, 1000);
camera.position.z = 5;

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(innerWidth, innerHeight);
document.body.appendChild(renderer.domElement);

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x49e0ff });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);
scene.add(new THREE.DirectionalLight(0xffffff, 2));

function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
animate();

Rendering

The renderer draws your scene from the point of view of a camera onto a canvas. WebGLRenderer is the primary renderer; WebGPURenderer is the emerging next-generation backend.

WebGLRenderer setup

const renderer = new THREE.WebGLRenderer({
  canvas: document.querySelector('#app'),
  antialias: true,
  alpha: false,
  powerPreference: 'high-performance'
});
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setClearColor(0x0b0e14, 1);

// Color management & tone mapping
renderer.outputColorSpace = THREE.SRGBColorSpace;
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;

The render loop

function tick() {
  requestAnimationFrame(tick);
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(tick); // preferred — required for WebXR

Handling resize

window.addEventListener('resize', () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});

Render targets (off-screen rendering)

const rt = new THREE.WebGLRenderTarget(1024, 1024, {
  minFilter: THREE.LinearFilter,
  magFilter: THREE.LinearFilter,
  format: THREE.RGBAFormat
});
renderer.setRenderTarget(rt);
renderer.render(scene, camera);
renderer.setRenderTarget(null); // back to screen

material.map = rt.texture; // use as texture elsewhere

Scene Management

Scene is the root node of a tree of Object3D instances (meshes, lights, groups, cameras). Understanding the hierarchy, transforms, and disposal is essential for larger apps.

Scene, groups & hierarchy

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x0b0e14);
scene.fog = new THREE.Fog(0x0b0e14, 10, 50); // or THREE.FogExp2

const group = new THREE.Group();
group.add(mesh1, mesh2);
scene.add(group);

group.position.set(0, 1, 0);
group.rotation.y = Math.PI / 4;
group.scale.setScalar(2);

// traverse the whole tree
scene.traverse((obj) => {
  if (obj.isMesh) obj.castShadow = true;
});

Layers (selective rendering)

mesh.layers.enable(1);
camera.layers.enable(1); // camera now also renders layer 1
camera.layers.set(0);    // camera renders only layer 0

Disposing resources

function disposeObject(obj) {
  obj.geometry?.dispose();
  if (Array.isArray(obj.material)) obj.material.forEach(m => m.dispose());
  else obj.material?.dispose();
}
scene.remove(mesh);
disposeObject(mesh);

Cameras

Cameras define the viewpoint used to render a scene. Three.js provides perspective, orthographic, cube, stereo, and array cameras.

PerspectiveCamera

const camera = new THREE.PerspectiveCamera(
  50,                              // fov (degrees)
  window.innerWidth / window.innerHeight, // aspect
  0.1,                             // near
  1000                             // far
);
camera.position.set(4, 3, 6);
camera.lookAt(0, 0, 0);

OrthographicCamera

const aspect = window.innerWidth / window.innerHeight;
const d = 5;
const camera = new THREE.OrthographicCamera(-d * aspect, d * aspect, d, -d, 0.1, 100);
camera.position.set(10, 10, 10);
camera.lookAt(0, 0, 0);

CubeCamera (dynamic reflections)

const cubeRenderTarget = new THREE.WebGLCubeRenderTarget(256);
const cubeCamera = new THREE.CubeCamera(0.1, 1000, cubeRenderTarget);
scene.add(cubeCamera);

material.envMap = cubeRenderTarget.texture;

function animate() {
  cubeCamera.update(renderer, scene);
  renderer.render(scene, camera);
}

ArrayCamera (multi-viewport, e.g. split-screen/VR)

const cameras = [];
for (let i = 0; i < 2; i++) {
  const cam = new THREE.PerspectiveCamera(50, 0.5 * innerWidth / innerHeight, 0.1, 100);
  cam.viewport = new THREE.Vector4(i * innerWidth / 2, 0, innerWidth / 2, innerHeight);
  cam.position.set(i * 2, 1, 5);
  cameras.push(cam);
}
const arrayCamera = new THREE.ArrayCamera(cameras);

const vertices = new Float32Array([
  -1, -1, 0,

Materials

Materials define how geometry surfaces are shaded — from unlit flat colors to full physically-based rendering (PBR) and custom GLSL shaders.

Common material types

new THREE.MeshBasicMaterial({ color: 0xffffff });        // unlit
new THREE.MeshLambertMaterial({ color: 0xffffff });       // diffuse-only lighting
new THREE.MeshPhongMaterial({ shininess: 100 });          // specular highlights
new THREE.MeshStandardMaterial({                          // PBR metal/roughness
  color: 0x49e0ff, metalness: 0.6, roughness: 0.3
});
new THREE.MeshPhysicalMaterial({                           // PBR + clearcoat/transmission
  metalness: 0, roughness: 0.1, clearcoat: 1, transmission: 0.9, ior: 1.5
});
new THREE.MeshToonMaterial();
new THREE.MeshNormalMaterial();
new THREE.MeshDepthMaterial();
new THREE.LineBasicMaterial({ color: 0xffffff });
new THREE.PointsMaterial({ size: 0.1 });
new THREE.SpriteMaterial({ map: texture });

ShaderMaterial (custom GLSL)

const material = new THREE.ShaderMaterial({
  uniforms: {
    uTime: { value: 0 },
    uColor: { value: new THREE.Color(0x49e0ff) }
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform float uTime;
    uniform vec3 uColor;
    varying vec2 vUv;
    void main() {
      vec3 color = uColor * (0.5 + 0.5 * sin(uTime + vUv.x * 10.0));
      gl_FragColor = vec4(color, 1.0);
    }
  `
});
// in the render loop: material.uniforms.uTime.value = clock.getElapsedTime();

NodeMaterial (TSL, WebGPURenderer)

import { color, time, sin, vec3 } from 'three/tsl';
import { MeshBasicNodeMaterial } from 'three/webgpu';

const material = new MeshBasicNodeMaterial();
material.colorNode = color(0x49e0ff).mul(sin(time).mul(0.5).add(0.5));

Textures

Textures map image data onto geometry. Three.js supports 2D textures, cube maps, video textures, canvas textures, data textures and compressed formats.

Loading & configuring a texture

const loader = new THREE.TextureLoader();
const texture = loader.load('textures/wood-diffuse.jpg');

texture.wrapS = THREE.RepeatWrapping;
texture.wrapT = THREE.RepeatWrapping;
texture.repeat.set(4, 4);
texture.colorSpace = THREE.SRGBColorSpace; // for color/albedo maps
texture.anisotropy = renderer.capabilities.getMaxAnisotropy();
texture.minFilter = THREE.LinearMipmapLinearFilter;

const material = new THREE.MeshStandardMaterial({
  map: texture,
  normalMap: loader.load('textures/wood-normal.jpg'),
  roughnessMap: loader.load('textures/wood-roughness.jpg'),
  aoMap: loader.load('textures/wood-ao.jpg'),
});

Cube / environment maps

const cubeLoader = new THREE.CubeTextureLoader().setPath('textures/env/');
const envMap = cubeLoader.load(['px.jpg','nx.jpg','py.jpg','ny.jpg','pz.jpg','nz.jpg']);
scene.background = envMap;
scene.environment = envMap; // used for PBR reflections on all materials

// HDR environment via RGBELoader + PMREMGenerator
import { RGBELoader } from 'three/addons/loaders/RGBELoader.js';
const pmrem = new THREE.PMREMGenerator(renderer);
new RGBELoader().load('studio.hdr', (hdr) => {
  scene.environment = pmrem.fromEquirectangular(hdr).texture;
});

Video, canvas & data textures

video.src = 'clip.mp4'; video.loop = true; video.muted = true; video.play();
const videoTexture = new THREE.VideoTexture(video);

const data = new Uint8Array([255, 0, 0, 255]); // 1x1 red pixel

Lighting

Lights illuminate materials that respond to light (Lambert, Phong, Standard, Physical). MeshBasicMaterial ignores lighting entirely.

Light types

scene.add(new THREE.AmbientLight(0x404050, 1));            // uniform, no shadows
scene.add(new THREE.HemisphereLight(0x88ccff, 0x442200, 1)); // sky/ground gradient

const dir = new THREE.DirectionalLight(0xffffff, 2);        // sun-like, parallel rays
dir.position.set(5, 10, 7);
scene.add(dir);

const point = new THREE.PointLight(0xff7ac6, 3, 20, 2);     // omnidirectional, with decay
point.position.set(0, 3, 0);
scene.add(point);

const spot = new THREE.SpotLight(0x49e0ff, 5, 20, Math.PI / 6, 0.3, 1);
spot.position.set(0, 5, 0);
spot.target.position.set(0, 0, 0);
scene.add(spot, spot.target);

const rect = new THREE.RectAreaLight(0xffffff, 5, 4, 2);    // soft area light (studio look)
rect.position.set(0, 3, 3);
rect.lookAt(0, 0, 0);
scene.add(rect);

Light probes & image-based lighting

import { LightProbeGenerator } from 'three/addons/lights/LightProbeGenerator.js';
const lightProbe = LightProbeGenerator.fromCubeRenderTarget(renderer, cubeRenderTarget);
scene.add(lightProbe);

Shadows

Shadows are computed with shadow maps rendered from the light's point of view. Enable shadows globally, then flag casters/receivers individually.

Enabling shadows

renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap; // Basic, PCF, PCFSoft, VSM

directionalLight.castShadow = true;
directionalLight.shadow.mapSize.set(2048, 2048);
directionalLight.shadow.camera.near = 0.5;
directionalLight.shadow.camera.far = 50;
directionalLight.shadow.camera.left = -10;
directionalLight.shadow.camera.right = 10;
directionalLight.shadow.bias = -0.0005;

mesh.castShadow = true;
ground.receiveShadow = true;

Contact / baked alternatives

// Cheap fake shadow using a semi-transparent circular texture
const shadowMat = new THREE.MeshBasicMaterial({
  map: shadowTexture, transparent: true, opacity: 0.5, depthWrite: false
});
const blob = new THREE.Mesh(new THREE.PlaneGeometry(2, 2), shadowMat);
blob.rotation.x = -Math.PI / 2;

Animation

Animate manually using Clock, or drive skeletal/keyframe animation imported from files with AnimationMixer.

Clock-based manual animation

const clock = new THREE.Clock();
function animate() {
  const delta = clock.getDelta();
  const elapsed = clock.getElapsedTime();
  mesh.rotation.y += delta * 0.5;
  mesh.position.y = Math.sin(elapsed) * 0.5;
  renderer.render(scene, camera);
}
renderer.setAnimationLoop(animate);

AnimationMixer & keyframe clips (from GLTF)

const mixer = new THREE.AnimationMixer(model);
const action = mixer.clipAction(gltf.animations[0]);
action.setLoop(THREE.LoopRepeat);
action.play();

// crossfade between two actions
const walk = mixer.clipAction(gltf.animations[0]);
const run  = mixer.clipAction(gltf.animations[1]);
walk.play();
walk.crossFadeTo(run.play(), 0.5, true);

function animate() {
  mixer.update(clock.getDelta());
}

Custom keyframe tracks

const times = [0, 1, 2];
const values = [0, 0, 0,  0, 5, 0,  0, 0, 0]; // x,y,z per keyframe
const track = new THREE.VectorKeyframeTrack('.position', times, values);
const clip = new THREE.AnimationClip('bounce', 2, [track]);

const mixer = new THREE.AnimationMixer(mesh);
mixer.clipAction(clip).play();

Controls

Camera/interaction controls live in three/addons/controls/ and are not part of the core library.

OrbitControls

import { OrbitControls } from 'three/addons/controls/OrbitControls.js';

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true;
controls.dampingFactor = 0.05;
controls.minDistance = 2;
controls.maxDistance = 20;
controls.maxPolarAngle = Math.PI / 2;

function animate() {
  controls.update(); // required when damping/autoRotate is enabled
  renderer.render(scene, camera);
}

PointerLockControls (FPS-style)

import { PointerLockControls } from 'three/addons/controls/PointerLockControls.js';

Raycasting

Raycaster casts a ray into the scene to detect intersections — the backbone of mouse picking, click selection, and simple physics queries.

Mouse picking

const raycaster = new THREE.Raycaster();
const pointer = new THREE.Vector2();

window.addEventListener('pointermove', (event) => {
  pointer.x = (event.clientX / window.innerWidth) * 2 - 1;
  pointer.y = -(event.clientY / window.innerHeight) * 2 + 1;
});

function animate() {
  raycaster.setFromCamera(pointer, camera);
  const intersects = raycaster.intersectObjects(scene.children, true);
  if (intersects.length > 0) {
    const hit = intersects[0];
    hit.object.material.color.set(0xff7ac6);
    console.log(hit.point, hit.distance, hit.face);
  }
  renderer.render(scene, camera);
}

Click selection & layers filtering

renderer.domElement.addEventListener('click', () => {
  raycaster.setFromCamera(pointer, camera);
  raycaster.layers.set(1); // only test objects on layer 1
  const [hit] = raycaster.intersectObjects(selectable, false);
  if (hit) selectObject(hit.object);
});

Exporters

Serialize a scene or object graph back out to standard 3D interchange formats, useful for editors and content pipelines.

Physics

Three.js has no built-in physics engine — it integrates with external libraries such as cannon-es, Ammo.js, or Rapier. The pattern is always: step the physics world, then sync mesh transforms.

cannon-es integration

import * as CANNON from 'cannon-es';

const world = new CANNON.World({ gravity: new CANNON.Vec3(0, -9.82, 0) });

const groundBody = new CANNON.Body({ mass: 0, shape: new CANNON.Plane() });
groundBody.quaternion.setFromEuler(-Math.PI / 2, 0, 0);
world.addBody(groundBody);

const sphereBody = new CANNON.Body({
  mass: 1,
  shape: new CANNON.Sphere(0.5),
  position: new CANNON.Vec3(0, 5, 0)
});
world.addBody(sphereBody);

const clock = new THREE.Clock();
function animate() {
  world.step(1 / 60, clock.getDelta(), 3);
  sphereMesh.position.copy(sphereBody.position);
  sphereMesh.quaternion.copy(sphereBody.quaternion);
  renderer.render(scene, camera);
}

Rapier (WASM, fast) integration

import RAPIER from '@dimforge/rapier3d-compat';
await RAPIER.init();

const world = new RAPIER.World({ x: 0, y: -9.81, z: 0 });
const rigidBody = world.createRigidBody(RAPIER.RigidBodyDesc.dynamic().setTranslation(0, 5, 0));
world.createCollider(RAPIER.ColliderDesc.ball(0.5), rigidBody);

function animate() {
  world.step();
  const t = rigidBody.translation();
  mesh.position.set(t.x, t.y, t.z);
}

Particles

Particle systems use Points with a PointsMaterial or a custom ShaderMaterial to render thousands of points efficiently in a single draw call.

Basic point cloud

const count = 5000;
const positions = new Float32Array(count * 3);
for (let i = 0; i < count; i++) {
  positions.set([
    (Math.random() - 0.5) * 20,
    (Math.random() - 0.5) * 20,
    (Math.random() - 0.5) * 20
  ], i * 3);
}

const geometry = new THREE.BufferGeometry();
geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));

const material = new THREE.PointsMaterial({
  size: 0.05, color: 0x49e0ff, transparent: true, opacity: 0.8,
  map: sparkleTexture, alphaTest: 0.01, depthWrite: false,
  blending: THREE.AdditiveBlending
});

const particles = new THREE.Points(geometry, material);
scene.add(particles);

Animated custom-shader particles

const material = new THREE.ShaderMaterial({
  uniforms: { uTime: { value: 0 }, uSize: { value: 40 } },
  vertexShader: `
    uniform float uTime; uniform float uSize;
    void main() {
      vec3 pos = position;
      pos.y += sin(uTime + position.x) * 0.5;
      vec4 mv = modelViewMatrix * vec4(pos, 1.0);
      gl_PointSize = uSize / -mv.z;
      gl_Position = projectionMatrix * mv;
    }
  `,
  fragmentShader: `
    void main() {
      float d = length(gl_PointCoord - vec2(0.5));
      if (d > 0.5) discard;
      gl_FragColor = vec4(0.3, 0.9, 1.0, 1.0 - d * 2.0);
    }
  `,
  transparent: true
});

Post-Processing / Effects

EffectComposer chains full-screen render passes for effects like bloom, depth of field, anti-aliasing, and outlines.

EffectComposer pipeline

import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';
import { OutputPass } from 'three/addons/postprocessing/OutputPass.js';
import { SMAAPass } from 'three/addons/postprocessing/SMAAPass.js';

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));

const bloom = new UnrealBloomPass(new THREE.Vector2(innerWidth, innerHeight), 1.2, 0.4, 0.85);
composer.addPass(bloom);

composer.addPass(new SMAAPass(innerWidth * renderer.getPixelRatio(), innerHeight * renderer.getPixelRatio()));
composer.addPass(new OutputPass());

function animate() {
  composer.render(); // replaces renderer.render(scene, camera)
}

Audio

Three.js wraps the Web Audio API with AudioListener, Audio (non-positional), and PositionalAudio (3D, distance-attenuated) which can be attached to any Object3D.

Global (non-positional) audio

const listener = new THREE.AudioListener();
camera.add(listener);

const sound = new THREE.Audio(listener);
const audioLoader = new THREE.AudioLoader();
audioLoader.load('sounds/ambient.mp3', (buffer) => {
  sound.setBuffer(buffer);
  sound.setLoop(true);
  sound.setVolume(0.5);
  sound.play();
});

Positional (3D spatial) audio

const posSound = new THREE.PositionalAudio(listener);
audioLoader.load('sounds/engine.mp3', (buffer) => {
  posSound.setBuffer(buffer);
  posSound.setRefDistance(5);
  posSound.setLoop(true);
  posSound.play();
});
carMesh.add(posSound); // sound moves and attenuates with the mesh

// Analyser for visualizers
const analyser = new THREE.AudioAnalyser(sound, 32);
const frequencyData = analyser.getFrequencyData();

const mrt = new THREE.WebGLRenderTarget(innerWidth, innerHeight, { count: 3 });

Enabling AR + hit testing

import { ARButton } from 'three/addons/webxr/ARButton.js';

document.body.appendChild(ARButton.createButton(renderer, { requiredFeatures: ['hit-test'] }));

renderer.xr.addEventListener('sessionstart', async () => {
  const session = renderer.xr.getSession();
  const viewerSpace = await session.requestReferenceSpace('viewer');
  const hitTestSource = await session.requestHitTestSource({ space: viewerSpace });
});

Performance Tips

  • Reuse geometries/materials; avoid creating new ones per frame.
  • Use InstancedMesh for repeated objects.
  • Merge static geometry into fewer draw calls.
  • Dispose geometries, materials, and textures when removing objects.
  • Cap setPixelRatio at 2 on high-DPI screens.
  • Use compressed textures (KTX2/Basis) for large scenes.
  • Use LOD and frustum culling for large worlds.
  • Prefer renderer.setAnimationLoop over manual rAF (required for XR).
