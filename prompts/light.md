Using HTML, create a light sandbox. Users should be able to create, move, delete, remove, rotate:
- Flashlights (completely customizable wavelength spectrum) + preset wavelength spectrum (white LED, sunlight, etc...)
- Laser (customizable wavelength)
- Polarizing filter
- Convex/concave lens (customizable focal length)
- Straight mirrors
- Curved mirrors
- Diffraction gratings (customizable parameters)
- Prisms (customizable parameters)
- Colored glass (blocks customizable wavelength spectrum, customizable reflectance)
- Light blockers
- Sensors

Light should be colored where applicable (eg. a red light should be red, a white light should be white, white light from a prism should be properly rainbow colored, a bright light should appear brighter than a dimmer light)
The simulation should be physically accurate and use real formulas instead of arbitrary approximations.

Notes: 
- Flashlights do not shoot light in a perfectly straight line. The user should be able to fully customize beam divergence.
- Prisms experience internal reflection. Users should also be able to customize this.
- 
Use a clean, minimal, dark-themed design. Prioritize UI organization and friendliness over a dense, feature-packed UI.
