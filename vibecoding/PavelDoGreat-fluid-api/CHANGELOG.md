# Changelog

## 2.0.0

- Consolidated the supplied FluidSimulation variants into a single dependency-free UMD library.
- Preserved the Pavel Dobryakov WebGL fluid solver and rendering pipeline.
- Unified camelCase and legacy uppercase configuration keys with input validation.
- Added visual presets, quality presets, named color palettes, transparent output/checkerboard controls, and dithering configuration.
- Included explicit start/stop/pause/resume/destroy lifecycle operations, manual ticking, resize handling, visibility pausing, WebGL context-loss recovery, and error events.
- Included pointer and hover interaction, scripted splats/strokes, event subscriptions, diagnostics, and capture/export helpers.
- Added documentation, a standalone demo, license attribution, and Node smoke tests.
