What was ported

The high-performance solver in src/ of taichi_mpm (not the 88-line version) was translated to self-contained C++17, compiled with the WASI SDK to a WebAssembly reactor module (with and without SIMD128), embedded into this page and driven through a C API that mirrors the original Python interface (add_particles, add_articulation, level sets, scripted motions, frame_update sources).
