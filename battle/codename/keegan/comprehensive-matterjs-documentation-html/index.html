Getting Started

setup

Matter.js is a single UMD bundle. Load it from a CDN or install via npm — the global Matter namespace exposes every module.

Install

// CDN
<script src="https://cdnjs.cloudflare.com/ajax/libs/matter-js/0.19.0/matter.min.js"></script>

// npm
npm install matter-js

// ES modules
import Matter from 'matter-js';

Your first simulation

// module aliases
const { Engine, Render, Runner, Bodies, Composite, Mouse, MouseConstraint } = Matter;

// 1. create engine & world
const engine = Engine.create();
const world = engine.world;

// 2. create renderer
const render = Render.create({
  element: document.body,
  engine: engine,
  options: { width: 800, height: 600, wireframes: false }
});

// 3. add bodies
const ground = Bodies.rectangle(400, 580, 810, 40, { isStatic: true });
const box    = Bodies.rectangle(400, 200, 80, 80);
Composite.add(world, [ground, box]);

// 4. add mouse interaction
const mouse = Mouse.create(render.canvas);
Composite.add(world, MouseConstraint.create({ mouse }));
render.mouse = mouse;

// 5. run
Render.run(render);
Runner.run(Runner.create(), engine);
How these docs work: every module below documents its constructor options, properties, methods and events, with copyable examples and — where useful — a live simulation you can play with directly on the page.

04

World

core

Matter.World is a backwards-compatible alias of Matter.Composite. The engine's root scene graph (engine.world) is a Composite, and all Composite methods apply to it.

// these are equivalent
Matter.World.add(engine.world, body);
Matter.Composite.add(engine.world, body);

// create a standalone world
const world = Matter.World.create({ gravity: { y: 0.5 } });
Note: New code should prefer Composite. World exists purely for API compatibility with older tutorials.

FAQ & Pitfalls

tips

Bodies jitter or tunnel through each other

Raise solver iterations: Engine.create({ positionIterations: 8, velocityIterations: 6 }). For very fast bodies, cap Runner delta or sub-step manually.

A body I moved with setPosition stays asleep

Sleeping bodies aren't re-evaluated. Wake it: Matter.Sleeping.set(body, false) — or enable engine.enableSleeping only when you need the perf win.

Collision filters explained

Each body has collisionFilter = { group, category, mask }. Same non-zero group → always collide (positive) or never (negative). Otherwise, a collision happens when (mask & category) !== 0 on both sides. See the live Collision demo above.

How do I remove a body cleanly?

Matter.Composite.remove(engine.world, body). For a full reset: Matter.Composite.clear(engine.world, false) (keep static = false removes the ground too — re-add it).

Retina / high-DPI canvases

Pass pixelRatio: 'auto' in Render options, or call Render.setPixelRatio(render, window.devicePixelRatio). Mouse coordinates stay correct automatically.

Cleanup when destroying a simulation

Stop both loops: Matter.Render.stop(render) and Matter.Runner.stop(runner), then Matter.Events.off(engine) to drop listeners, and clear the world.
