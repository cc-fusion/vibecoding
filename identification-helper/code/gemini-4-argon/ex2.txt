Launch Instructions
Development Server: Run npm run dev and open the local URL in any WebGL-capable browser.
Production Build / Single-File Output: Run npm run build (dist/index.html is already built and ready to serve via npm run preview or any static host).
Controls:
W A S D: Move · Space: Jump / Swim Up (Double-tap Space or F toggles Flight in Creative mode)
Shift: Sneak (includes cliff edge-guard for safe bridge building) · Ctrl (or double-tap W): Sprint
Mouse (or Arrow keys): Look · Left-Click: Mine / Attack · Right-Click: Place Block / Use Station / Ignite TNT / Eat Food
1–9 or Scroll Wheel: Select Hotbar Slot · E: Inventory & Crafting · F3: Toggle Diagnostics · Esc: Pause & Settings
Summary of Implemented Features
Plain HTML, CSS & Modular Vanilla JS Architecture:
Built directly on index.html, src/style.css, and modular ES JavaScript (src/main.js and subsystems) with Three.js (three), without React in the runtime bundle.
Procedural Pixel-Art Texture Atlas & Custom Voxel Shaders (src/engine/TextureAtlas.js):
Procedurally generated 16×16 pixel-art textures packed into a 256×256 atlas with 8px extruded gutters to prevent UV seam bleeding.
Custom GLSL chunk shaders combining directional face shading, smooth 4-sample per-vertex Ambient Occlusion (with anisotropy-corrected quad diagonals), sky-light canopy/water attenuation, flickering warm BFS torch/crystal block lighting, underwater tinting, and horizon-matched fog.
Isometric 3D block icons for UI slots and 3D voxel-extruded handheld tools, weapons, torches, and blocks rendered in a dedicated depth-cleared viewmodel pass.
Multi-Biome World Generation, Caves & Landmarks (src/world/WorldGen.js, src/world/World.js):
Seeded deterministic Simplex/FBM terrain across 7 biomes (Emerald Plains, Whispering Forest, Sunbaked Dunes, Golden Beach, Frostpine Taiga, Alpine Crags, Azure Ocean).
3D cave networks, depth-stratified ore veins (Coal, Iron, Gold, Diamond, Luminescent Crystal), bioluminescent cave mushrooms, Oak/Birch/Spruce trees, cacti, wildflowers, gravity-settling Sand & Gravel, and rare Desert Wells / Wayfarer Camps.
Distance-sorted chunk streaming around a configurable render distance (3–8 chunks).
Physics, Survival/Creative Progression, Inventory & Crafting (src/physics/PlayerController.js, src/game/Inventory.js):
Sub-stepped axis-separated (Y → X → Z) AABB collision, coyote-time jumping, Shift-sneak edge protection, water buoyancy/oxygen mechanics, fall damage, hunger/health regeneration, and Creative mode flight.
Exact Amanatides & Woo 3D DDA voxel raycasting, progressive mining with 8-stage crack overlays, tool speed/durability tiers (Wood, Stone, Iron, Gold, Diamond), and station-aware categorized crafting & furnace smelting (Hand, Crafting Table, Furnace, plus Creative Palette).
Living World, Atmosphere, Audio & Persistence (src/entities/EntityManager.js, src/atmosphere/SkyWeather.js, src/audio/SoundManager.js, src/storage/SaveManager.js):
Passive (Sheep, Pig, Chicken) and nocturnal hostile (Zombie, Cave Slime) articulated voxel creatures, magnetic 3D item drops, particle bursts, and chain-reacting ignitable TNT craters.
Dynamic 24-hour day-night cycle with orbiting voxel Sun & Moon, stars, drifting 3D voxel clouds, and biome-aware Rain/Snowfall.
Web Audio API procedural sound synthesis for material-specific footsteps, mining, breaking, placement, item pickups, eating, splashes, combat, and explosions.
Persistent multi-world storage using compressed chunk-edit deltas via IndexedDB with a write-through localStorage fallback and JSON world export/import.
Verification & Testing
Automated Engine Suite (node tests/verify_engine.mjs): Verified seed determinism, 7-biome generation, bedrock/ore placement, cross-chunk BFS torch lighting propagation and ghost-free light removal, sand gravity, delta reload fidelity, AABB landing & Shift-sneak cliff guard, DDA raycasting, and multi-tier crafting/smelting recipes.
Headless Chromium WebGL E2E Verification: Tested live dist/index.html in Playwright Chromium with WebGL enabled; visually inspected rendered screenshots and fixed three issues uncovered during runtime testing:
Reset residual camera.rotation.z roll when transitioning from the Title Screen's orbiting lookAt panorama to first-person gameplay.
Switched water wave displacement from chunk-local coordinates to world-space coordinates (modelMatrix * position) to eliminate hairline wave seams at chunk boundaries.
Added timeout guards and write-through localStorage caching in SaveManager so world saves and reloads complete reliably even if indexedDB.open is blocked in headless/sandboxed contexts.
Remaining Limitations
Single-Player Local Sandbox: Multiplayer networking, redstone-style logic circuits, nether/end dimensions, and complex cellular fluid simulation (beyond lateral sea-level water fill and buoyancy) are out of scope.
Chunk Height & Render Range: World height is fixed at 96 blocks and render distance caps at 8 chunks (272×272 blocks) to maintain smooth JavaScript chunk meshing and memory usage in the browser.
