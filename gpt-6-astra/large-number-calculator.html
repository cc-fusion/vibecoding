Numerics, domains, and execution

Arithmetic uses a BigInt decimal significand and a BigInt decimal exponent. Transcendental functions use guarded numerical series and Newton iteration. Extra working precision is requested automatically for large trigonometric arguments and sensitive exponentiation.

This is finite-precision numerical arithmetic, not symbolic algebra or certified interval arithmetic. Extreme cancellation can require you to increase precision. Displayed digits are numerical approximations.

Only real results are supported. Use cbrt(-8) for negative cube roots. Inverse cotangent uses (0, π); inverse secant and cosecant use their principal real branches. 0^0 is defined as 1.

Iterative algorithms yield regularly so the progress display and Cancel button remain usable. Native BigInt operations cannot themselves be interrupted. Available memory and browser limits ultimately constrain input size and precision.
