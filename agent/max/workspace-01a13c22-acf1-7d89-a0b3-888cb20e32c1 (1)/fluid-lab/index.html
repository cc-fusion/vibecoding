FLUX / THE NUMERICS

A direct route to
divergence-free flow.

A GPU implementation of Chorin’s projection method.
No Jacobi. No Gauss–Seidel. No pressure iterations.

01 / A periodic, staggered grid

Pressure and dye live at cell centers. Horizontal and vertical velocities live on their respective faces (MAC layout). All sampling wraps at domain boundaries. The normalized domain is 1 × 1; h = 1/n.

02 / Split the time step

Forces + explicit viscosity → advection → pressure → projection

Diffusion uses a five-point forward-Euler update. Advection uses explicitly backtraced characteristics and bilinear semi-Lagrangian sampling. The time step is automatically limited so ν Δt / h² ≤ 0.24. High viscosity or resolution may slow simulated time rather than destabilize the field.

03 / Solve once, spectrally

D u* → FFT → divide by λ(k) → inverse FFT → u = u* − Gq

The pressure impulse q = Δt p solves ∇²q = D u*. We use the exact discrete MAC Laplacian eigenvalue −4/h² [sin²(πkx/n) + sin²(πky/n)]. The zero mode is set to zero. Matching divergence and gradient operators makes the projection divergence-free to floating-point accuracy.

04 / Preserve the detail

Optional BFECC advects forward, backward with the same frozen velocity, corrects the source by half the round-trip error, then advects again. A donor-neighborhood clamp prevents new extrema. It is not a replacement for the pressure projection and is not strictly mass-conserving.

05 / Scale with the GPU

Stockham radix-2 FFTs use 4 log₂(n) fullscreen butterfly passes for the forward and inverse 2D transforms combined. Complexity is O(N log N), where N = n² cells. Advection has no CPU cell loops or iterative solves: every cell is handled in parallel by a fragment shader.

1024² uses approximately 85 MiB of numerical textures; 2048² uses 341 MiB. Total GPU usage is higher. Performance depends on the GPU; this is not a 60 fps guarantee. Bilinear sampling is manual, so float-linear texture extensions are unnecessary.
