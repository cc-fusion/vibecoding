VOXEL CORE / DEVELOPER GUIDE

Build your own world.

A small, framework-free voxel renderer. Import the engine, provide voxel data, and keep your application logic yours.

ES modulesThree.jsNo build stepNo gameplay systems

01 / Get started

Serve the project folder with python3 -m http.server 3000. Open localhost:3000. All dependencies are included locally. 

import { VoxelEngine, VoxelWorld } from './engine/engine.js';

const engine = new VoxelEngine(document.querySelector('#viewport'), {
  palette: ['#000000', '#8aaa69'],
  workers: 2
});
const world = new VoxelWorld();
for (let x = 0; x < 16; x++) {
  for (let z = 0; z < 16; z++) world.set(x, 0, z, 1);
}
engine.setWorld(world);
engine.on('ready', () => engine.frameWorld());

02 / Small API. Full control.

world.set(x, y, z, id)Edit a voxel; 0 removes it. Neighbor meshes invalidate automatically.
engine.setMeshing({ ao, greedy })Rebuild with different meshing settings.
engine.pick(x, y)Raycast canvas-relative pixels to a voxel.
engine.on('frame', ({ dt }) => {})Attach your own per-frame systems.
engine.scene / camera / rendererAccess the underlying Three.js objects directly.
engine.dispose()Release GPU buffers, workers, observers, and controls.
